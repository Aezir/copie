Copie 使用教程

全功能速览，从基础到进阶。

笔记管理

Copie 的基本单位是「笔记」，每条笔记有一个标题和若干文本块。

新建
点右上角 + 按钮
改标题
直接点笔记列表里的标题文字，弹出编辑面板后修改
删除
左滑条目，点红色删除图标；删后底部弹「撤销」可恢复
收藏 / 置顶
左滑条目，点星号（收藏）或图钉（置顶）
多选
长按任意条目进入多选模式，顶部出现批量操作栏
搜索
顶部搜索框，同时搜标题和文本块内容
撤销删除：无论单条还是批量删除，底部都会出现「撤销」提示，5 秒内可点击恢复。
文本块

一条笔记里可以有多个文本块，适合存密码、代码片段、地址等不同类型的内容。

添加块
打开笔记编辑面板，点底部「添加文本块」
复制块
点条目展开后，点每个块右侧的复制图标
删除块
展开后左滑文本块，点红色删除图标；支持撤销
代码高亮

文本块内容会自动识别代码并着色，支持字符串、数字、关键词、注释、URL 等类型。

  • 在「设置 → 显示 → 代码高亮」中开关
  • 开启后，编辑时底层实时着色，光标位置仍可正常输入中文
隐私模式

开启后，列表里每个文本块的内容都会打码——只显示前 4 个字符和后 4 个字符，中间替换为 ••••。

  • 在「设置 → 显示 → 隐私模式」中开关
  • 打码仅影响显示，复制、导出的内容仍是原文
  • 内容不足 8 字符时不打码，避免泄漏长度信息
适合在人多或截图时打开，拍屏看不到真实内容。
标题栏元信息

每条笔记标题旁可以显示小标签：创建/修改时间、字数、Token 估算值（供 AI 参考用量）。

  • 在「设置 → 标题栏显示」中逐项开关
  • Token 按约 3.5 字符 / token 估算，仅供参考
主题定制

外观设置在「设置 → 主题」中，随时可改。

外观模式
日间 / 夜间 / 跟随系统，三选一
主题色
从预设色块中选，或点「自定义」打开取色盘自定义
背景色
同上，影响整个页面底色
数据备份与导入

所有数据默认只存在本机浏览器（IndexedDB），建议定期手动导出备份。

导出
「设置 → 导出全部」，保存为 .json 文件；App 内存至「下载」文件夹
导入文件
「设置 → 导入文件」，选 JSON 文件，合并入库，不覆盖现有数据
剪贴板导入
复制 JSON 文本后，点「从剪贴板导入」
复制全部
将全部数据以 JSON 格式复制到剪贴板，方便粘贴到别处
数据格式：导出的 JSON 可直接重新导入，也可粘贴给 AI 请求格式转换后再导入。导入旁的 ? 按钮有 AI 提示词参考。
云同步（端对端加密）

通过你自己的 GitHub 私有仓库同步，数据在设备上加密后才上传，GitHub 看不到明文。

一次性配置步骤：

  1. 在 GitHub 里新建一个私有仓库，命名为 copie-data
  2. 生成一个「fine-grained」个人 token，只授权 copie-data 仓库的 Contents 读写权限
  3. 在「设置 → 云同步」粘贴 token，设置主密码（换设备时填同一个，丢了数据解不开）
  4. 点「连接并同步」
换设备：填同一个 token 和同一个主密码，点「连接并同步」即可把数据拉过来。
隐私：加密采用 PBKDF2（210 000 次迭代）+ AES-GCM，只有你的密码能解开。

悬浮球 仅 App

悬浮球是一个可以常驻在所有应用上层的小按钮，点击可快速打开 Copie。

  • 首次打开 App 会请求「显示在其他应用上层」权限，允许后悬浮球自动出现
  • 「设置 → 悬浮球 → 显示悬浮球」开关控制显示 / 隐藏
  • 拖动滑块调整悬浮球大小（36–76 dp）
悬浮横条 仅 App

在 Copie 里，把任意笔记条目长按并拖出去，就能让它以「横条」的形式悬浮在所有应用上方，方便在别的 App 里来回复制内容。

拎出
在笔记列表里长按一个条目，原卡变半透明，拖到屏幕边缘松手即创建悬浮横条
吸附合并
把一个横条拖近另一个，它们会自动吸附并叠成一叠
拆开
长按叠中的一张卡，拖到空处松手，可以单独分离出来
取消拎出
长按拖起后，放回原位或在空处松手不动，原卡自动恢复
复制
点横条上任意文本块旁的复制图标，内容进剪贴板
隐私模式同样适用于悬浮横条——开启后横条里的文字也会打码，但复制仍是原文。
自动更新检测 仅 App

App 每次启动时会联网检查新版本。如果有壳（原生层）更新，会弹窗提示下载。

  • 弹窗会明确显示文件名（如 copie-1.6.apk），按名安装，避免装成下载夹里的旧包
  • 只有 App 壳本身有功能更新时才需要重装；普通界面升级刷新即生效，无需任何操作
