# Copie 复制箱

本地"复制箱"：手机窗口形状的单页 PWA 应用，用来存 baseurl/key、常用参数、人设、小剧场等经常要复制的内容。

## 特性
- 数据存浏览器 IndexedDB，支持 JSON 导出/导入
- 标签筛选、排序、多选批量操作
- 左滑置顶 / 收藏 / 删除；就地编辑
- **PWA**：可"添加到主屏幕/安装"，离线可用，自适应电脑和手机
- **云同步（一次配置，之后全自动）**：设置里粘贴一个 GitHub token（classic，勾 repo），App 自动建**私有**仓库 `copie-data` 存数据，改动后自动上传、换设备打开自动拉取

> 云同步注意：Token 只存本机浏览器，不进代码；数据存你自己的**私有**仓库。CORS 限制下同步需在托管网址（如 Netlify）下使用，本地 file:// 打开可能不通。跨设备为“整体最后写入者优先”，首次连接会自动合并两端数据。

## 文件
- `index.html` —— 应用本体（单文件）
- `manifest.webmanifest` —— PWA 应用清单
- `sw.js` —— Service Worker，离线缓存
- `icon.svg` —— 应用图标

## 使用
- **本地**：直接用浏览器打开 `index.html` 即可（离线安装功能需联网托管才生效）。
- **安装为应用（PWA）**：需把本目录托管到 https 网址（如 GitHub Pages），再用浏览器打开，选"安装 / 添加到主屏幕"。

> 注意：应用里记录的数据存在**本机浏览器**，不进 Git。备份请用 App 内"导出 JSON"。
